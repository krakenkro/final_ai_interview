## Follow-up Prompt Set

1. Is the bottleneck in React rendering, browser layout, paint, or network?
2. What would you measure first before optimizing?
3. Why is this jank visible to the user?
4. What is the cheapest change with the highest likely impact?
5. How would you avoid premature optimization here?
6. Which CSS or DOM operation is likely expensive?
7. How would you confirm the improvement after the fix?
