## Follow-up Prompt Set

1. Why did you place state in that component instead of higher up?
2. What bug could appear if your list keys were unstable?
3. How would this component change if several children needed the same data?
4. What part of this logic belongs in props versus state?
5. How would you debug unnecessary rerenders here?
6. What trade-off did you make between reuse and simplicity?
7. How would this design behave as the feature grows?
