## Follow-up Prompt Set

1. Can you show this on a real component from your project?
2. Why should this data not be mutated directly here?
3. Where would you use `computed`, and where would you prefer `watch`?
4. What would start breaking if this component kept growing?
5. How would you extract the shared logic into a composable without over-engineering it?
6. What changes if the same state is needed by neighboring components?
7. Какой компромисс ты принимаешь, чтобы API этого компонента оставался простым?
