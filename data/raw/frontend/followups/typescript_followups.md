## Follow-up Prompt Set

1. Why is this safer than using `any`?
2. What bug would the type system prevent here?
3. Why is a union better than a loose set of optional fields here?
4. What would happen if this generic had no constraint?
5. Where would inference be enough, and where would you annotate explicitly?
6. How would this type design age as the API or component surface grows?
7. Which part of this example depends on narrowing?
