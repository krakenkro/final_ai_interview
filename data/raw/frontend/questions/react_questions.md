## Curated Question Set

### Junior-friendly

1. What is a React component and why is a UI split into components?
2. What is JSX and how is it different from plain HTML?
3. What is the difference between props and state?
4. How do you render a list in React and why is the `key` prop important?
5. How do you conditionally show one piece of UI instead of another?

### Middle-level

6. When would you lift state up instead of keeping it in a child component?
7. How would you explain one-way data flow to a teammate?
8. What problems appear when list keys are unstable or based on array index?
9. How do you decide which component should own a piece of state?
10. Walk through a real feature where state, props, and event handlers worked together.

## Follow-up Prompts

- Give a concrete project example.
- What trade-off did you make in state placement?
- What bug could happen if keys are wrong?
- How would this change if the component tree grows?
