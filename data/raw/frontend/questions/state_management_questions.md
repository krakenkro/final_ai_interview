## Curated Question Set

1. How do you decide where a piece of state should live?
2. What does "lifting state up" mean and when is it needed?
3. What is the difference between controlled and uncontrolled components?
4. What problems appear when shared state is duplicated in several components?
5. How would you coordinate two sibling components that need to stay in sync?
6. What is a "single source of truth" in a React app?
7. When is local component state enough, and when do you need shared state?
8. Tell me about a case where state structure affected maintainability or bugs.
