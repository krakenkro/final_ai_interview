## Strong Answer Patterns

### Pattern 1. Concept explanation

1. Define React concept in simple terms.
2. Contrast it with the nearest confusing concept.
3. Give a small UI example.
4. Mention one trade-off, rerender implication, or common bug.

### Pattern 2. Practical reasoning

1. Describe where the concept appears in a real feature.
2. Explain how data or control flows.
3. Show what goes wrong if the concept is misunderstood.
4. End with maintainability or UX impact.
