## Quick Reference

- Page file: route by convention
- layout: shared route shell
- SSR: render on server per request
- CSR: render on client
- SSG: pre-rendered static output
- `useFetch`: fetch with Nuxt integration
- `useAsyncData`: async data keyed in app context
- middleware: route-level guard or setup logic
- hydration: client attaches behavior to server HTML
