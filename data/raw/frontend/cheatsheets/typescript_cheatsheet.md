## Quick Reference

- Primitive types: `string`, `number`, `boolean`
- Arrays: `T[]` or `Array<T>`
- Object type: describes field structure
- Union: value may be one of several types
- Type alias: reusable name for a type
- Interface: reusable object contract
- Narrowing: safe refinement of union values
- Inference: TypeScript often derives the type automatically
