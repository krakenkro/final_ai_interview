## Quick Reference

- Component: reusable UI unit, usually a function returning JSX.
- Props: external input passed from parent to child.
- State: internal changing data that triggers rerender.
- JSX: markup-like syntax inside JavaScript.
- Conditional rendering: `if`, ternary, `&&`.
- List rendering: `map` plus stable `key`.
- Lift state up: move shared changing data to common parent.
- Event handlers: connect user actions to state updates.
