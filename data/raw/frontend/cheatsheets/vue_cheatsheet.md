## Quick Reference

- Component: reusable UI unit with a clear responsibility
- `props`: input from parent
- `emits`: output intent to parent
- `ref`: reactive single value
- `reactive`: reactive object-like state
- `computed`: derived value
- `watch`: side effects on change
- slot: extension point in component API
- composable: reusable stateful logic
