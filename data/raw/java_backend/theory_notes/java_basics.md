## Source Summary

The `Learn Java` portal on dev.java highlights the core foundations expected from backend engineers: language basics, classes and objects, interfaces, inheritance, generics, exceptions, collections, streams, and concurrency-oriented topics such as virtual threads. For interview prep, this gives a clean official baseline for Java language reasoning rather than framework-only knowledge.

## Key Notes

### Language and OOP Foundations

- Java uses classes and objects as core building blocks.
- Interfaces define contracts and support abstraction.
- Inheritance and composition should be understood together, with composition often preferred for flexibility.
- Records are useful for immutable data modeling.

### Types and Generics

- Strong typing is central to Java APIs.
- Generics allow reusable, type-safe abstractions.
- Interview answers should connect generics to collections, service contracts, and avoiding unsafe casts.

### Error Handling

- Exceptions model exceptional flows separately from normal return values.
- Candidates should know checked vs unchecked exceptions at a practical level.

### Collections and Streams

- The Collections Framework is fundamental for storing and retrieving in-memory data.
- Stream API supports declarative processing, but should not be used blindly when readability or debugging suffers.

### Concurrency and Runtime Awareness

- Backend engineers should understand threads, concurrency basics, and when shared mutable state becomes risky.
- JVM and core tooling matter when discussing performance and troubleshooting.

## Interview-Relevant Takeaways

- Strong candidates can explain `class`, `interface`, `record`, `collection`, and `generic` in concrete backend scenarios.
- Good answers compare alternatives instead of giving dictionary definitions.
- Middle-level answers usually connect collections and concurrency to API/server behavior.
