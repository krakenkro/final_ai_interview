## Curated Question Set

2. When can caching improve latency, and when can it create correctness risks?
3. What is cache invalidation and why is it hard?
4. What kind of data is a bad fit for caching?
5. How would you reason about stale data versus system speed?
6. What can go wrong if a team adds caching too early?
7. How would you explain the difference between caching a computation and caching authoritative business state?
