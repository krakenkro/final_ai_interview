## Evaluation Dimensions

### 1. Fundamentals correctness

- `strong`: correctly explains core Java, Spring basics, SQL basics, or HTTP semantics.
- `medium`: mostly correct with small inaccuracies.
- `weak`: major confusion in backend fundamentals.

### 2. Structured reasoning

- `strong`: gives a clean step-by-step explanation.
- `medium`: partially structured but uneven.
- `weak`: fragmented or contradictory.

### 3. Practical examples

- `strong`: connects concepts to a small API, service, or data example.
- `medium`: example is simple but relevant.
- `weak`: no practical example.

### 4. Learning potential

- `strong`: open about limits, but shows sound engineering direction.
- `medium`: can improve with hints.
- `weak`: answers are memorized and brittle.

## Coaching Hints

- Prioritize clarity over breadth.
- Use small backend examples instead of abstract architecture prompts.
- Encourage comparison of alternatives in simple scenarios.
