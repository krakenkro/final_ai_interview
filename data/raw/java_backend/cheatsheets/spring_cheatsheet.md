## Quick Reference

- IoC container: creates and wires beans
- Dependency Injection: supplies dependencies instead of manual construction
- Bean: Spring-managed component
- Controller: HTTP boundary
- Service: business logic layer
- Repository: persistence/data access layer
- `@Transactional`: transaction boundary declaration
- Testability: improved through explicit, replaceable dependencies
