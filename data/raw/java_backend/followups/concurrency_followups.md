## Follow-up Prompt Set

1. Which resource is shared here?
2. What interleaving of operations would create the bug?
3. Is the risk in application memory, in the database, or in an external system?
4. What guarantee are you actually trying to protect?
5. How would retries change the failure mode?
6. What would you test to reproduce the race condition?
7. How would you design observability for this issue?
