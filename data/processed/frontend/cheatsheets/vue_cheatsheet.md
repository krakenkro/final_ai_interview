## Краткий справочник

- компонент: переиспользуемый кусок UI с чёткой ответственностью
- `props`: входные данные от родителя
- `emits`: способ сообщить наружу о действии
- `ref`: реактивное одиночное значение
- `reactive`: реактивное объектное состояние
- `computed`: производное значение
- `watch`: реакция на изменение и побочный эффект
- slot: точка расширения API компонента
- composable: переиспользуемая stateful-логика
