## Краткий справочник

- Компонент: переиспользуемая единица UI
- Props: входные данные от родителя
- State: изменяемые данные компонента
- JSX: разметка внутри JavaScript
- Conditional rendering: `if`, ternary, `&&`
- Lists: `map` + стабильный `key`
- Lift state up: перенос общего состояния в общего родителя
