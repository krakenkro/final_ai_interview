## Краткое резюме

React строит интерфейс из независимых компонентов. Компонент обычно представляет маленький кусок UI, получает данные через props и хранит изменяемые данные через state. UI обновляется как реакция на изменения state и пользовательские события.

## Ключевые идеи

1. Компоненты:
   JavaScript-функции, которые возвращают JSX и могут вкладываться друг в друга.
2. JSX:
   Разметка внутри JavaScript. Требует корректного синтаксиса и общего родителя для соседних узлов.
3. Props:
   Канал передачи данных сверху вниз.
4. State:
   Внутренняя память компонента для изменяемых значений.
5. Условный рендеринг:
   Используются обычные конструкции JavaScript: `if`, ternary, `&&`.
6. Списки:
   Обычно строятся через `map`; каждому элементу нужен стабильный `key`.
7. Подъём состояния:
   Если одни и те же данные нужны нескольким дочерним компонентам, состояние поднимают в ближайший общий родитель.

## Что важно для интервью

- Уметь различать `props` и `state` без расплывчатых формулировок.
- Объяснять, зачем React разбивает интерфейс на компоненты.
- Понимать, почему плохие `key` приводят к багам в списках.
- Уметь связать структуру state с предсказуемостью UI.
