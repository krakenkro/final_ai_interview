## Краткий справочник

- Class: реализация и состояние
- Interface: контракт
- Record: компактная immutable-модель
- Generic: type-safe абстракция
- Exception: сигнал ошибочного сценария
- Collections: `List`, `Set`, `Map`
- Stream: декларативная обработка данных
