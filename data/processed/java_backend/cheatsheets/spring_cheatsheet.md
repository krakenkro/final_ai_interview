## Краткий справочник

- IoC container: создаёт и связывает beans
- DI: внедряет зависимости
- Bean: Spring-managed компонент
- Controller: HTTP-граница
- Service: бизнес-логика
- Repository: слой доступа к данным
- `@Transactional`: граница транзакции
