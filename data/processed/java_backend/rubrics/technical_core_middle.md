## Критерии оценки

1. Корректность:
   понимание Java, Spring, SQL и transaction semantics.
2. Системное мышление:
   объяснение границ, failure modes и trade-offs.
3. Production relevance:
   связь с latency, consistency, testability, maintainability.
4. Коммуникация:
   ясный и связный ответ.

## Быстрые сигналы

- Сильный ответ:
  правильно, практично и с объяснением последствий.
- Средний ответ:
  mostly correct, но без глубины.
- Слабый ответ:
  запоминание терминов без инженерной логики.
