## Краткое резюме

Для Java backend-интервью база строится вокруг языка, ООП, generics, exceptions, collections и понимания runtime-поведения. Хороший кандидат умеет обсуждать Java не как набор терминов, а как инструмент проектирования серверной логики.

## Ключевые идеи

1. Классы и интерфейсы:
   классы задают реализацию и состояние, интерфейсы формируют контракты.
2. Наследование и композиция:
   композиция часто безопаснее и гибче наследования.
3. Generics:
   дают type safety и уменьшают риск runtime-cast ошибок.
4. Exceptions:
   помогают отделять штатный поток от ошибочного.
5. Collections:
   нужно понимать различия `List`, `Set`, `Map` и их practical use cases.
6. Streams:
   полезны для декларативной обработки, но не всегда улучшают читаемость.

## Что важно для интервью

- Уметь сравнивать подходы, а не только давать определения.
- Приводить примеры из сервисов, DTO, доменных моделей и коллекций.
- Понимать, где language-level решение влияет на поддержку и тестируемость.

## Сигналы сильного ответа

- Кандидат объясняет компромиссы между разными типами абстракций.
- Говорит про type safety и читаемость.
- Не смешивает ООП-концепции с framework-магией.
